# ledaw

run desktop app
```sh
cargo run
```

build
```sh
cargo build
```

build firmware
```sh
cargo build -p firmware
```

test
```sh
cargo test
```

lint + format
```sh
# rustup component add clippy rustfmt  # if you don't have it
cargo clippy --all-targets --all-features
cargo fmt --check
```

## Firmware

see [`firmware/README.md`](firmware/README.md) for flashing the rp2350.
